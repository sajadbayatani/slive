# Release Process — Slive

This document describes how Slive releases are cut, published to GitHub Releases, and published to Docker Hub with traceable OCI metadata.

## Trigger

- **Tag push:** `git tag v0.8.0 && git push origin v0.8.0` triggers `.github/workflows/release.yml` (`on: push: tags: ['v*']`).
- **Manual dry-run:** `workflow_dispatch` with `dry_run: true` runs `validate` + `build` but skips `release` and `docker` jobs (`if: ${{ !inputs.dry_run }}`).

Releases are only created on annotated tags `v*`. Branch pushes do not publish.

## CI

CI is defined in `.github/workflows/ci.yml` and runs on `push` to `main` and on every `pull_request`:

- **lint** job: `gofmt -l` (format check, ignoring `.gocache/`) + `go vet ./...`.
- **test** job: `go test ./... -race -count=1` (untagged) + `go test -tags slive_internal ./... -race -count=1` (dual-tag matrix verifying hook-free and hook-gated paths), plus `git status --porcelain reports/` assert for baseline churn.
- **sdk-smoke** job: `go build ./...` + `go run ./examples/basic-room`, `publish-subscribe`, `health` (each greps expected log lines), plus baseline churn assert.
- **coverage** job: `go test ./... -coverprofile=coverage.out -covermode=atomic`, `go tool cover -func=coverage.out`, upload `coverage.out` as artifact (retention 7 days, not hardcoded percentage).
- Caching: `actions/cache@v4` with `path: .gocache/mod`, key `${{ runner.os }}-go-1.24-${{ hashFiles('go.sum') }}`, and `GOMODCACHE: ${{ github.workspace }}/.gocache/mod` (repository-local cache).

Local equivalent:

```sh
export GOMODCACHE="$PWD/.gocache/mod"
go vet ./...
go test ./... -race -count=1
go test -tags slive_internal ./... -race -count=1
```

## Coverage

Coverage is generated with standard Go tooling (no external service required):

```sh
make cover
# → go test ./... -coverprofile=coverage.out -covermode=atomic && go tool cover -func=coverage.out
cat coverage.out
go tool cover -html=coverage.out -o coverage.html  # or make cover-html
```

CI `coverage` job produces the same `coverage.out` and uploads it via `actions/upload-artifact@v4` (`name: coverage.out`). The README `Coverage` badge `https://img.shields.io/badge/coverage-go%20cover-blue` links to `https://github.com/sajadbayatani/slive/actions/workflows/ci.yml` where the artifact can be downloaded — not a hardcoded percentage. An external service such as `https://coveralls.io/github/sajadbayatani/slive` may be added later without changing the pipeline.

## GitHub Releases

- `validate` job: `go vet`, `gofmt -l`, `go test ./... -race` (untagged + `slive_internal`).
- `build` job (`needs: validate`): matrix `linux/darwin × amd64/arm64`, `CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -X main.version=${{ github.ref_name }} -X main.commit=${{ github.sha }} -X main.date=$(date -u +%Y-%m-%dT%H:%M:%SZ)"`, tar to `dist/slive_<version>_<goos>_<goarch>.tar.gz` + `dist/checksums.txt` (`sha256sum`), upload as artifacts.
- `release` job (`needs: build`, `if: ${{ !inputs.dry_run }}`): `softprops/action-gh-release@v2` with `generate_release_notes: true`, `fail_on_unmatched_files: true`, `prerelease: ${{ contains(github.ref_name, '-rc') }}`, `make_latest: ${{ !contains(github.ref_name, '-rc') }}`.

Artifacts are traceable: Git tag `v0.8.0` → `VERSION=v0.8.0`, `COMMIT=$GITHUB_SHA`, `DATE` RFC3339 UTC.

### Tag Strategy

Tags are generated by `docker/metadata-action@v5` with `flavor: latest=false` and `type=semver` patterns. `latest` moves only on stable releases (prerelease excluded via `!contains(github.ref_name, '-rc')`).

| Git tag | Docker tags produced | Notes |
|---------|----------------------|-------|
| `v0.8.0` | `0.8.0`, `0.8`, `0`, `latest` | Stable: full semver + major/minor shorthands + `latest` |
| `v0.8.1` | `0.8.1`, `0.8`, `0`, `latest` | `0.8` and `0` float to newest patch/minor |
| `v0.9.0` | `0.9.0`, `0.9`, `0`, `latest` | Minor bump |
| `v1.0.0` | `1.0.0`, `1.0`, `1`, `latest` | Major bump |
| `v0.8.0-rc.1` | `0.8.0-rc.1` only | Prerelease: no `0.8`, `0`, or `latest` |

Configuration in `.github/workflows/release.yml`:

```yaml
flavor: |
  latest=false
tags: |
  type=semver,pattern={{version}}
  type=semver,pattern={{major}}.{{minor}}
  type=semver,pattern={{major}}
  type=raw,value=latest,enable=${{ !contains(github.ref_name, '-rc') }}
```

This ensures `latest` never moves on `-rc`, `-beta`, `-alpha` prereleases.

### Build

- **Workflow job:** `docker` (`needs: build`, `runs-on: ubuntu-latest`, `permissions: contents: read`, `if: ${{ !inputs.dry_run }}`)
- Steps: `actions/checkout@v4` (`ref: ${{ github.ref }}`, `fetch-depth: 0`), `docker/setup-qemu-action@v3`, `docker/setup-buildx-action@v3`, `docker/login-action@v3`, `docker/metadata-action@v5`, `docker/build-push-action@v6`
- **Platforms:** `linux/amd64,linux/arm64` (multi-arch via QEMU + Buildx)
- **Build args:** `VERSION=${{ github.ref_name }}`, `COMMIT=${{ github.sha }}`, `DATE=${{ fromJSON(steps.meta.outputs.json).labels['org.opencontainers.image.created'] }}` — same values injected into binary via `go build -ldflags "-X main.version=$VERSION -X main.commit=$COMMIT -X main.date=$DATE"`
- **Push:** `push: true` (skipped automatically on `workflow_dispatch` dry-run)
- **Tags/Labels:** `tags: ${{ steps.meta.outputs.tags }}`, `labels: ${{ steps.meta.outputs.labels }}`

Local validation (no push):

```sh
make docker-buildx VERSION=v0.8.0 COMMIT=$(git rev-parse --short HEAD) DATE=$(date -u +%Y-%m-%dT%H:%M:%SZ)
# or
docker buildx build --platform linux/amd64,linux/arm64 --build-arg VERSION=v0.8.0 --build-arg COMMIT=$(git rev-parse --short HEAD) --build-arg DATE=$(date -u +%Y-%m-%dT%H:%M:%SZ) -t sajadbayatani/slive:v0.8.0 .
```

Single-arch local build:

```sh
make docker-build VERSION=v0.8.0-test
docker inspect slive:local --format '{{json .Config.Labels}}' | jq
```

### Secrets

| Secret | Purpose | Required | Least privilege |
|--------|---------|----------|-----------------|
| `DOCKERHUB_USERNAME` | Docker Hub login username | yes (for push) | Read+Write on `sajadbayatani/slive` repo only; use access token, not password |
| `DOCKERHUB_TOKEN` | Docker Hub access token / password | yes (for push) | Same scope; create at https://hub.docker.com/settings/security as scoped token |
| `GITHUB_TOKEN` | GitHub Release creation | auto-provided | `contents: write` only (workflow-level `permissions: contents: write`; `docker` job uses `contents: read`) |

Do not commit tokens. Create repo secrets at `Settings → Secrets and variables → Actions`. Without these secrets the `docker` job fails at `docker/login-action@v3`; `workflow_dispatch` dry-run skips the job entirely.

### Traceability

Every image carries OCI annotations and Docker labels for `tag → commit → image` traceability:

- `org.opencontainers.image.version` = Git tag (`v0.8.0`)
- `org.opencontainers.image.revision` = commit SHA (`${{ github.sha }}`)
- `org.opencontainers.image.source` = `https://github.com/sajadbayatani/slive`
- `org.opencontainers.image.created` = build date (RFC3339 UTC)

`Dockerfile` fallback (kept minimal `gcr.io/distroless/static-debian12` runtime):

```dockerfile
ARG VERSION=dev
ARG COMMIT=unknown
ARG DATE=unknown
LABEL org.opencontainers.image.version=$VERSION \
      org.opencontainers.image.revision=$COMMIT \
      org.opencontainers.image.source="https://github.com/sajadbayatani/slive" \
      org.opencontainers.image.created=$DATE
```

When built via CI, `docker/metadata-action@v5` injects the same labels via `labels: ${{ steps.meta.outputs.labels }}` (which include `org.opencontainers.image.*`); the Dockerfile `LABEL` is the fallback for local builds.

Verify locally or on a pulled image:

```sh
docker inspect --format '{{ index .Config.Labels "org.opencontainers.image.version"}}' sajadbayatani/slive:0.8.0
# → v0.8.0

docker inspect --format '{{ index .Config.Labels "org.opencontainers.image.revision"}}' sajadbayatani/slive:0.8.0
# → abc123...

docker inspect --format '{{ index .Config.Labels "org.opencontainers.image.created"}}' sajadbayatani/slive:0.8.0
# → 2026-09-01T12:00:00Z

docker inspect sajadbayatani/slive:0.8.0 --format '{{json .Config.Labels}}' | jq
```

Binary version matches image label:

```sh
docker run --rm sajadbayatani/slive:0.8.0 --version
# slive v0.8.0 (commit abc123, built 2026-09-01T12:00:00Z)
```

### Multi-arch note

`linux/arm64` via QEMU is slow (~4-6 min). The `docker` job `needs: build` so it only runs after validation passes and does not block `release` binary publication.

## Versioning

- **Source of truth:** Git tag `v0.8.0`. No `VERSION` file is committed; the tag drives `VERSION` in the build.
- **Injection:** `go build -trimpath -ldflags "-s -w -X main.version=$VERSION -X main.commit=$COMMIT -X main.date=$DATE"` with `CGO_ENABLED=0`. `Makefile` defaults: `VERSION ?= $(shell git describe --tags --always --dirty)`, `COMMIT ?= $(shell git rev-parse --short HEAD)`, `DATE ?= $(shell date -u +%Y-%m-%dT%H:%M:%SZ)`; release workflow passes `VERSION=${{ github.ref_name }}`, `COMMIT=${{ github.sha }}`, `DATE` from metadata labels.
- **Traceability:** `slive --version` prints `slive <version> (commit <sha>, built <date>)` to stdout and exits 0 before `config.Load`. Example:

```sh
./bin/slive --version
# slive v0.8.0 (commit abc123, built 2026-09-01T12:00:00Z)

docker run --rm sajadbayatani/slive:0.8.0 --version
# slive v0.8.0 (commit abc123, built 2026-09-01T12:00:00Z)

# Verify slive --version traceability matches Docker label:
docker inspect --format '{{ index .Config.Labels "org.opencontainers.image.version"}}' sajadbayatani/slive:0.8.0
```

Tag → commit → image → binary are traceable via matching `slive --version` output and OCI labels.

## Release Checklist

Copy this checklist for each release (all commands with `GOMODCACHE="$PWD/.gocache/mod"`):

- [ ] tests pass (`go test ./... -race -count=1`)
- [ ] race pass (`go test -tags slive_internal ./... -race -count=1` and `go test ./... -race -count=1` clean)
- [ ] build pass (`go build ./...` and `make build` / `make dist`)
- [ ] coverage generated (`make cover` produces `coverage.out` and `go tool cover -func=coverage.out` succeeds)
- [ ] version tag created (`git tag v0.8.0 && git push origin v0.8.0`; tag is annotated, `v*` triggers release)
- [ ] GitHub Release created (workflow `release` job, `softprops/action-gh-release@v2`, `generate_release_notes: true`)
- [ ] binaries uploaded (matrix `linux/darwin × amd64/arm64` tars `dist/slive_<version>_<goos>_<goarch>.tar.gz`)
- [ ] checksums uploaded (`dist/checksums.txt` via `sha256sum` / `shasum -a 256`)
- [ ] Docker image published (`sajadbayatani/slive` via `docker/build-push-action@v6`, `push: true`)
- [ ] Docker tag matches Git tag (verify `docker inspect` label `org.opencontainers.image.version == v0.8.0` and semver shorthand `0.8.0/0.8/0/latest`)
- [ ] README badges updated automatically (CI, Coverage, Release, Docker badges point to official `shields.io`/`github`/`hub.docker.com` URLs)
- [ ] traceability verified (`git tag → commit → image → binary`: `slive --version` commit matches `github.sha` and `org.opencontainers.image.revision`)
